  • 五张卡片回答「池子里有多少 → 已有多少 → 还缺多少 → 缺的里有多少能用」。
  • 缺口 = 累计发现 − 已有外链 − 竞品；数字为 0 时先去「分析」跑一次。
  • 「累计发现」是见过的域名，不等于已拥有——只有台账里已上线（live）的才算真外链。
  • 互链占比超过 30% 会提示 link scheme 风险，互链与目录站分开统计。
  • 今日队列是每日工作配额（默认 100，可在队列条直接改）：当天冻结一批、领走即出队、不自动补齐；配额是硬闸门，超了领取会直接被拒。「供给缺口 = 配额 − 本批」，点旁边的补候选可原地跑一次分析。
  • 白名单里的域名留在池中但不计入任何统计（总数/缺口/队列都跳过），适合自家站群与聚合站。
  • 失活待办（红条）只在近 7 天有链接失活时出现：域名已退回缺口，可重新排期；点「去台账处理」直接跳台账。
  • 上次分析变化对比最近两次运行：新增候选、转为无效、恢复有效、池总量——只看总数看不出「今天的涨是新的还是旧的」。
  • 补货：库存低于阈值时后台会自己再跑一次分析补候选（有冷却；连续扑空会翻倍退避）；「补候选」是手动立即触发。
  • 全部数字围绕顶部中心域名计算，切换域名即重算。
